Welcome to the Fullstack Template! This project provides a modern, batteries-included tech stack for building robust web applications with Next.js, Hono, Drizzle ORM, and more. Use this template as a foundation to quickly start new projects, following best practices for API design, database management, validation, authentication, and deployment.

## Stack

| Technology      | Purpose                                 | Docs / Links                                      |
|-----------------|-----------------------------------------|---------------------------------------------------|
| Next.js         | React framework for SSR & routing       | [nextjs.org](https://nextjs.org/)                 |
| tRPC            | End-to-end typesafe APIs made easy      | [trpc.io](https://trpc.io/)                       |
| Hono            | Fast, type-safe API routing (REST)      | [hono.dev](https://hono.dev/)                     |
| Drizzle ORM     | Type-safe SQL ORM for TypeScript        | [orm.drizzle.team](https://orm.drizzle.team/)     |
| Neon            | Serverless Postgres database            | [neon.tech](https://neon.tech/)                   |
| Clerk           | Authentication & user management        | [clerk.com](https://clerk.com/)                   |
| shadcn/ui       | Accessible, customizable UI components  | [ui.shadcn.com](https://ui.shadcn.com/)           |
| Zod + OpenAPI   | Validation & API schema docs            | [zod.dev](https://zod.dev/) / [zod-openapi](https://github.com/asteasolutions/zod-to-openapi) |
| Bun             | Unit & Integration tests                | [bun.com](https://bun.com/docs/cli/test)          |
| TypeScript      | Type safety across the stack            | [typescriptlang.org](https://www.typescriptlang.org/) |
