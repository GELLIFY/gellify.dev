## AWS Deployment Guide

This template provides AWS Amplify Hosting stubs that mirror the Preview/Production flow. Enable these when your project chooses AWS as the provider.

### Overview

- Preview: optional job in `deploy-preview.yml` (commented `deploy_aws`) after DB prep
- Production: optional job in `deploy-production.yml` (commented `deploy_aws_production`) gated on CI and migrations
- Cleanup: optional step in `cleanup-preview.yml` to delete the Amplify preview branch

### Why Amplify Hosting

- Fast GitHub integration, automatic previews per branch, simple env management; closest UX to Vercel for Next.js
- Alternatives:
  - App Runner/ECS Fargate for containerized Next.js
  - S3 + CloudFront for static-only frontends

### Prerequisites (when enabling)

- AWS account with Amplify Hosting app created and connected to this repo
- IAM user/role with permissions for Amplify and branch management

Required Secrets/Variables

- Secrets
  - `AWS_ACCESS_KEY_ID`
  - `AWS_SECRET_ACCESS_KEY`
- Variables
  - `AWS_REGION` (e.g., `eu-central-1`)
  - `AMPLIFY_APP_ID`

### Enabling Preview Deployment

In `.github/workflows/deploy-preview.yml`, uncomment the `deploy_aws` job stub.

Inputs to provide

```yaml
with:
  AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
  AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
  AWS_REGION: ${{ vars.AWS_REGION }}
  AMPLIFY_APP_ID: ${{ vars.AMPLIFY_APP_ID }}
  AMPLIFY_BRANCH: preview/pr-${{ github.event.number }}-${{ needs.prepare_db.outputs.pr_branch_name }}
  DATABASE_URL: ${{ needs.prepare_db.outputs.neon_db_url }}
  NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY: ${{ secrets.NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY }}
```

Composite action used: `.github/workflows/cd/aws/deploy-preview/action.yml`

- Currently a stub; uncomment the AWS CLI steps to:
  - Create/update the Amplify branch
  - Set environment variables for build/runtime
  - Trigger a build and optionally fetch the preview URL (`branch.webUrl`)

### Enabling Production Deployment

In `.github/workflows/deploy-production.yml`, uncomment the `deploy_aws_production` job.

Inputs to provide

```yaml
with:
  AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
  AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
  AWS_REGION: ${{ vars.AWS_REGION }}
  AMPLIFY_APP_ID: ${{ vars.AMPLIFY_APP_ID }}
  AMPLIFY_BRANCH: main
  DATABASE_URL: ${{ secrets.DATABASE_URL }}
  NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY: ${{ secrets.NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY }}
```

Composite action used: `.github/workflows/cd/aws/deploy-production/action.yml`

- Uncomment the AWS CLI steps to kick off a production build and update environment variables

### Cleanup on PR Close

In `.github/workflows/cleanup-preview.yml`, uncomment the AWS cleanup step and pass the inputs:

```yaml
with:
  AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
  AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
  AWS_REGION: ${{ vars.AWS_REGION }}
  AMPLIFY_APP_ID: ${{ vars.AMPLIFY_APP_ID }}
  AMPLIFY_BRANCH: preview/pr-${{ github.event.number }}-${{ steps.branch_name.outputs.current_branch }}
```

Composite action used: `.github/workflows/cd/aws/cleanup-preview/action.yml`

- Uncomment to delete the Amplify preview branch when the PR closes

### IAM Policy (example minimal)

Grant least privilege to manage branches and start jobs in Amplify Hosting:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "amplify:GetBranch",
        "amplify:CreateBranch",
        "amplify:UpdateBranch",
        "amplify:DeleteBranch",
        "amplify:StartJob",
        "amplify:GetJob",
        "amplify:GetApp"
      ],
      "Resource": "arn:aws:amplify:*:*:apps/<AMPLIFY_APP_ID>/*"
    }
  ]
}
```

### Troubleshooting

- Branch exists errors: ensure branch naming matches what Amplify expects; sanitize special chars if needed
- Preview URL missing: ensure the fetch step queries `branch.webUrl` after branch creation and build
- Env var not applied: confirm `update-branch --environment-variables` is used or configure in Amplify console
